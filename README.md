# PLC 编码器数值 1-9 展示与监控

这是一个无需构建工具、无需外部依赖的单文件 HTML 控制面板，用于演示和验证 PLC 增量式编码器的 A/B 两相正交解码逻辑。

## 文件

- [plc-encoder-monitor.html](./plc-encoder-monitor.html)：完整可运行页面，HTML、CSS 和 JavaScript 全部内置。

## 运行

直接用现代浏览器打开 `plc-encoder-monitor.html` 即可。页面加载后默认处于停止状态，当前数值为 `1`。

当前页面使用浏览器本地模拟数据，不会直接连接 PLC。后续接入真实 PLC 时，可通过代码中的数据适配器接口提交样本，例如 `adapter.publish({ a: 0, b: 1, timestamp: Date.now() })`。

## 功能

- 四状态正交解码：支持正转加 1、反转减 1。
- 自动忽略非法状态跳变，并统计非法跳变次数。
- 10 ms 软件去抖，减少输入抖动造成的误判。
- 循环模式和限位模式。
- 启动、停止、复位、正转一步、反转一步。
- 自动模拟正转运行，可调节 1–20 脉冲/秒。
- A/B 相状态调试。
- 运行状态、方向、A/B 电平、连接状态和工作模式指示。
- 有效脉冲数、非法跳变数、运行时间和最后动作时间统计。
- 最近 60 次有效变化的数值趋势图。
- 操作事件日志、清空日志和 CSV 导出。
- 键盘快捷键：`→` 正转一步、`←` 反转一步、`R` 复位。
- 边界模式和模拟速度使用 `localStorage` 保存。
- 适配桌面与窄屏显示，并提供基本键盘无障碍支持。

## 正交解码规则

正转状态顺序为 `00 → 01 → 11 → 10 → 00`。沿顺序变化记为 `+1`，反向变化记为 `-1`。一次跨越两个状态的变化属于非法跳变：系统会重新同步相位基准，但不会改变编码器数值。

## PLC 接入预留

页面将数据接收与页面渲染分离。当前使用本地模拟适配器；将来可以编写 WebSocket、REST API 或 PLC 网关适配器，把规范化的 A/B 样本交给 `publish()`，而无需改动界面渲染逻辑。

## 许可

本示例未附加特定开源许可证；如需公开分发，可根据项目需要补充许可证文件。
